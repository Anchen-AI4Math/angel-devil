**`wallTrace_never_returns`.** Let \(D\) be any function taking a finite ordered list of points of \(\mathbb Z^2\) to either no point or one point. Suppose that, for every nonempty list \(h\) beginning at \((0,0)\) whose successive coordinate differences each lie in \([-2,2]\), whenever \(D(h)\) selects \(z\), then \(z\ne(0,0)\) and, for every entry \(v\) of \(h\) except its final entry, at least one coordinate difference between \(z\) and \(v\) has absolute value greater than \(2\). There is no restriction on \(D\) at other lists, and selecting no point satisfies this condition without further requirements. Define the following trajectory. A wall is a pair \((v,d)\), where \(v\in\mathbb Z^2\) and \(d\) is one of east, north, west, south; its outside point is \(v+e_d\), with \(e_d\) the corresponding unit vector. Write \(t(d)\) for the rotation east \(\mapsto\) north \(\mapsto\) west \(\mapsto\) south \(\mapsto\) east, and \(-d\) for the opposite direction. For any set \(B\), define \(F_B(v,d)\) by putting \(a=v+e_{t(d)}\), \(b=a+e_d\), and returning \((v,t(d))\) if \(a\notin B\), otherwise \((a,d)\) if \(b\notin B\), and otherwise \((b,-t(d))\). This rule is defined even when \((v,d)\) does not separate a point of \(B\) from a point outside \(B\). Set \(w_0=((-1,0),\mathrm{east})\). For a finite list \(L\) of optional points, let \(B(L)\) consist of all points with negative first coordinate together with every point selected in \(L\); repetitions and entries selecting no point add no further points. Define \(H([])=w_0\) and \(H(L)=F_{B(L)}(F_{B(L)}(H(L^-)))\) for nonempty \(L\), where \(L^-\) deletes the last entry. Start play with visited list \([(0,0)]\) and optional-point list \(L_0=[]\); at each round append \(D\) of the current visited list to the optional-point list and then append the outside point of \(H\) of that updated list to the visited list. Let \(L_k\) be the optional-point list after \(k\) rounds. Define \(W_0=w_0\) and \(W_{i+1}=F_{B(L_{\lfloor i/2\rfloor+1})}(W_i)\) for every natural number \(i\), so two consecutive wall steps use the same round's obstacle set. The assertion is that, for every natural number \(n>0\), \(W_n\ne w_0\); equality at \(n=0\) is explicitly excluded, and the conclusion concerns the complete wall pair, not merely its outside point.

**`niceAngelWins_of_wall_no_return`.** Assume the following statement for every function \(D\) from finite lists of points of \(\mathbb Z^2\) to optional points: if, on every list starting at the origin and having successive coordinate differences bounded in absolute value by \(2\), each point \(z\) selected by \(D\) is different from the origin and has some coordinate difference of absolute value greater than \(2\) from each entry other than the last, then a wall trajectory defined below never equals its initial wall at any positive natural index. To define that trajectory, represent a wall by \((v,d)\), with \(d\) east, north, west, or south, outside point \(v+e_d\), opposite direction \(-d\), and rotation \(t\) given by east \(\mapsto\) north \(\mapsto\) west \(\mapsto\) south \(\mapsto\) east. For any obstacle set \(B\), put \(a=v+e_{t(d)}\), \(b=a+e_d\), and define \(F_B(v,d)\) to be \((v,t(d))\) if \(a\notin B\), \((a,d)\) if \(a\in B\) and \(b\notin B\), and \((b,-t(d))\) otherwise, without requiring that the input wall be a boundary wall. If \(L_k\) is the resulting optional-point list after \(k\) rounds, the trajectory in the assumption is \(W_0=w_0\), \(W_{i+1}=F_{B(L_{\lfloor i/2\rfloor+1})}(W_i)\), and its asserted nonreturn is \(W_n\ne w_0\) for all \(n>0\). Under this assumption, there exists a single function \(A\) taking a visited-point list and an optional-point list to a point, such that for every \(D\) satisfying the stated restriction, the following play survives and escapes: start at the origin with an empty optional-point list; each round append \(D\) of the current visited list to that list, and then append \(A\) of the current visited list and updated optional-point list to the visited list. Moreover, for every natural number \(N\), including \(0\), some position at a natural time \(n\), possibly \(0\), lies outside \([-N,N]^2\). **WallWalk definitions.** Points are ordered pairs of integers, and a side is a pair of Boolean values: \((\mathrm{false},\mathrm{false})\), \((\mathrm{true},\mathrm{false})\), \((\mathrm{false},\mathrm{true})\), and \((\mathrm{true},\mathrm{true})\) denote east, north, west, and south respectively. The neighbor across a side is the point obtained by adding its unit vector; opposite side reverses that vector, and tangent side rotates directions east \(\mapsto\) north \(\mapsto\) west \(\mapsto\) south \(\mapsto\) east. A wall is a point-side pair \((v,d)\), its outside point is \(v+e_d\), and it is a boundary wall for a set \(B\subseteq\mathbb Z^2\) exactly when \(v\in B\) and \(v+e_d\notin B\). For the next-wall operation, put \(t=t(d)\), \(a=v+e_t\), and \(b=a+e_d\): return \((v,t)\) when \(a\notin B\), otherwise \((a,d)\) when \(b\notin B\), otherwise \((b,-t)\). The previous-wall operation uses exactly the same three branches with \(t=-t(d)\) instead; both operations are defined for every set and wall, including non-boundary walls, without an additional assertion here that the operations are inverses. The initial wall is \(((-1,0),\mathrm{east})\), whose outside point is the origin. The obstacle set associated with a finite list of optional points is the union of the half-plane \(x<0\) with all points appearing as selected entries; an absent selection adds nothing, and order and multiplicity do not affect this set. The history wall of the empty list is the initial wall; for a nonempty list, first compute the history wall after deleting its last entry, then apply the next-wall operation twice using the obstacle set of the full list for both steps. The wall-based angel is a function of a visited list and an optional-point list that ignores the visited list and returns the outside point of this history wall. For any devil function \(D\) from visited lists to optional points, play begins with the origin as its sole visited point and no optional entries; each round appends \(D\) of the visited list to the optional-point list and then appends the wall-based angel's output for the updated list to the visited list. The obstacle set for trace index \(i\) is the obstacle set after \(\lfloor i/2\rfloor+1\) such rounds, and the wall trace starts at the initial wall and applies one next-wall step with this index-dependent set at each successive index. These definitions impose no niceness, legal-move, or survival condition on \(D\) or on the generated play.
